Diagnóstico de Redes de Computadores

Identificação, análise e solução de problemas comuns em redes

Início Problemas Ferramentas Conclusão

Sobre o projeto

Este projeto apresenta situações comuns encontradas em redes de computadores. O objetivo é demonstrar como identificar possíveis problemas, analisar suas causas e aplicar procedimentos para solucioná-los utilizando comandos e ferramentas de diagnóstico.

Objetivo

Desenvolver a capacidade de identificar, analisar e solucionar problemas comuns de redes de computadores por meio de testes práticos e ferramentas de diagnóstico.

Problemas analisados

01

Computador sem acesso à internet

O que está acontecendo?

O computador está conectado à rede, mas não consegue acessar sites ou outros serviços disponíveis na internet.

Possíveis causas

  • Problema no roteador;
  • Falha na conexão com o provedor;
  • Configuração incorreta de IP;
  • Gateway incorreto;
  • Problema de DNS;
  • Problema no cabo ou na conexão Wi-Fi.

Como identificar?

Primeiro, podemos verificar as configurações de rede utilizando: 

ipconfig /all

Depois podemos testar a comunicação com o gateway: 

ping 192.168.1.1

Também podemos testar a comunicação com um endereço externo: 

ping 8.8.8.8

Como resolver?

Devemos verificar os cabos, o roteador, as configurações de IP e o gateway. Caso o computador utilize DHCP, podemos solicitar uma nova configuração: 

ipconfig /release
```

ipconfig /renew
```
02

Endereço IP incorreto

O que está acontecendo?

O computador possui um endereço IP que não pertence à rede correta ou apresenta uma configuração incompatível.

Possíveis causas

  • Configuração manual incorreta;
  • Falha no servidor DHCP;
  • Máscara de sub-rede incorreta;
  • Gateway incorreto;
  • Problemas de conexão com o roteador.

Como identificar?

ipconfig /all

Esse comando permite verificar o endereço IPv4, máscara, gateway, DNS e informações do DHCP.

Também podemos renovar o endereço IP:

ipconfig /release
```

ipconfig /renew
```

Como resolver?

A configuração de rede deve ser corrigida. Em redes que utilizam DHCP, o computador pode ser configurado para obter automaticamente um endereço IP.

03

Problema de DNS

O que está acontecendo?

O computador possui conexão com a internet, mas não consegue acessar sites utilizando seus nomes de domínio.

Possíveis causas

  • Servidor DNS indisponível;
  • DNS configurado incorretamente;
  • Falha temporária no servidor DNS;
  • Cache DNS com informações incorretas.

Como identificar?

Primeiro podemos testar um endereço IP:

ping 8.8.8.8

Depois podemos testar um domínio: 

ping google.com

Também podemos utilizar o comando nslookup: 

nslookup google.com

Como resolver?

Podemos verificar a configuração dos servidores DNS e limpar o cache DNS: 

ipconfig /flushdns

Após isso, o funcionamento do DNS pode ser testado novamente utilizando o comando nslookup.

04

Cabo de rede desconectado ou com defeito

O que está acontecendo?

O computador não consegue estabelecer uma conexão através do cabo Ethernet.

Possíveis causas

  • Cabo desconectado;
  • Cabo danificado;
  • Conector RJ-45 com problema;
  • Porta do switch ou roteador com defeito;
  • Placa de rede desativada.

Como identificar?

Primeiro devemos verificar fisicamente o cabo e as luzes indicadoras da porta de rede. 

ipconfig

O comando permite verificar o estado dos adaptadores de rede e identificar situações em que a mídia está desconectada.

Como resolver?

  • Reconectar o cabo;
  • Testar outro cabo de rede;
  • Testar outra porta do switch ou roteador;
  • Verificar se o adaptador está habilitado;
  • Realizar novamente os testes de conectividade.
05

Conflito de endereço IP

O que está acontecendo?

Dois dispositivos da mesma rede estão utilizando o mesmo endereço IP, causando problemas de comunicação.

Possíveis causas

  • Dois computadores configurados com o mesmo IP;
  • Configuração incorreta de IP estático;
  • Problema relacionado ao DHCP.

Como identificar?

Primeiro verificamos o endereço IP:

ipconfig

Também podemos consultar a tabela ARP: 

arp -a

A tabela ARP apresenta associações entre endereços IP e endereços MAC encontrados na rede.

Como resolver?

Os dispositivos devem possuir endereços IP diferentes. Quando a rede utiliza DHCP, podemos renovar a configuração: 

ipconfig /release
```

ipconfig /renew
```

Depois, podemos verificar novamente a configuração utilizando o comando ipconfig.

Ferramentas e comandos de diagnóstico

ipconfig

Exibe informações da configuração de rede, como endereço IP, máscara, gateway e servidores DNS.

ping

Testa a comunicação entre o computador e outro dispositivo ou endereço de rede.

ping 8.8.8.8

nslookup

Verifica a resolução de nomes de domínio através do DNS.

nslookup google.com

tracert

Mostra o caminho percorrido pelos pacotes até um destino.

tracert google.com

arp

Exibe informações sobre associações entre endereços IP e endereços MAC.

arp -a

Conclusão

O diagnóstico de problemas de rede depende da análise das diferentes partes da comunicação. Comandos como ipconfig, ping, nslookup, tracert e arp ajudam a identificar onde o problema está ocorrendo.

A utilização dessas ferramentas permite verificar configurações de IP, comunicação entre dispositivos, funcionamento do DNS e possíveis problemas físicos ou de configuração.

Dessa forma, o projeto demonstra procedimentos básicos que podem ser utilizados para analisar e solucionar problemas comuns em redes de computadores.
