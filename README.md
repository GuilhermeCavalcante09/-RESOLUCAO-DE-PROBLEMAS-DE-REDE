# Projeto de Diagnóstico de Redes de Computadores

## Sobre o projeto

Este projeto foi desenvolvido para apresentar situações comuns encontradas em uma rede de computadores, mostrando como identificar, analisar e solucionar problemas de conectividade.

O projeto utiliza uma página web desenvolvida com **HTML e CSS**, contendo explicações sobre os problemas, possíveis causas, comandos de diagnóstico e procedimentos de solução.

## Objetivo

Desenvolver a capacidade de identificar, analisar e solucionar problemas comuns de redes de computadores utilizando comandos e ferramentas de diagnóstico.

## Problemas analisados

O projeto apresenta cinco situações comuns:

1. Computador sem acesso à internet
2. Endereço IP incorreto
3. Problema de DNS
4. Cabo de rede desconectado ou com defeito
5. Conflito de endereço IP

Para cada situação são apresentados:

- O que está acontecendo;
- Possíveis causas;
- Comandos e procedimentos para identificar o problema;
- Formas de solucionar o problema.
